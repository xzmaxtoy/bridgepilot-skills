# 小红书 SEO: keywords and placement

XHS search is close to half of all traffic. SEO matters as much as content quality. (Public lore, not official.)

## 1. Four keyword types
| Type | What it is | Shape for a local service |
|---|---|---|
| 核心词 core | Category word, high volume | the service name in Chinese |
| 长尾词 long tail | Core word + place / scene / person | service + city, service + home situation |
| 需求词 need | The question the user types | "怎么…", "要多久", "值不值", "注意什么" |
| 转化词 conversion | Buying-intent word | service + 本地 / city + 推荐 (never a claim the profile cannot source) |
Pick 1 core word + 1-2 long-tail or need words per post. The client's own pool lives in `profile.json` > `keyword_pool`, not in this file.

## 2. Where keywords go (highest priority first)
1. Title, first half. The core word within the first 10 characters.
2. Body, first 100 characters: the core word once, naturally.
3. Body middle: long-tail and need words, spread naturally.
4. Topics (话题): existing, searched topics that carry a keyword.
5. First comment: one related need word.

## 3. Choosing words
1. The search box drop-down: type the core word and read the suggestions (high-volume words).
2. 相关搜索 at the bottom of the results page.
3. Competitor and similar posts: what keywords they use.
4. Low-competition long tail: words with volume but few notes.

## 4. Cautions
- Do not stuff keywords; unnatural text is rated low quality.
- Search traffic feeds the recommendation feed; the two are not independent.
- Check rank for the target keyword 48 hours after publishing; record it in the log.
- Title SEO and hook must both work. Never trade the hook away to fit a keyword.
- No absolute claims or contact data to "rank better".
